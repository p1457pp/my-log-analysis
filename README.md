# 📊 웹로그 분석 및 통계 보고서 생성 프로그램 (Web Log Analyzer)

SIST(`https://sist.co.kr`) 웹사이트 서버 로그 데이터를 분석하여 서비스 통계 보고서를 생성하고, GUI 화면 출력 및 파일 저장 기능을 제공하는 Java 기반 데스크톱 애플리케이션입니다.

---

## 🛠️ 기술 스택 (Tech Stack)
* **Language**: Java
* **UI/GUI**: Swing (`JOptionPane`, `JTextArea`, `JScrollPane`)
* **Data Structure**: `List`, `Set`, `Map`
* **Build / Distribution**: Runnable JAR

---

## 📋 프로젝트 개요
* **배경**: 서버에 쌓이는 사용자 검색/접속 로그(`sist_input_1`)를 파싱 및 분석하여 유의미한 서비스 통계 지표 산출
* **로그 데이터 구조**: 
  > `[응답결과][요청 URL (예: 요청URL?key=mongodb&query=sist)][요청 브라우저 종류][일자 시간]`
* **응답 코드 정의**: `200` (성공) | `404` (페이지 없음) | `403` (권한 없음) | `500` (서버 내부 오류)

---

## 🚀 주요 기능 (Key Features)

### 1. 🔐 사용자 인증 (Login)
프로그램 실행 시 접근 권한을 확인하기 위한 로그인 과정을 거칩니다.
* **`admin` / `1234`** : 전체 권한 (조회 및 리포트 파일 생성 가능)
* **`administrator` / `12345`** : 전체 권한 (조회 및 리포트 파일 생성 가능)
* **`root` / `1111`** : 조회 가능 / **리포트 파일 생성 권한 없음**

### 2. 📊 로그 데이터 분석 항목 (1 ~ 6번)
1. **최다 사용 키 및 횟수**: 검색 URL 파라미터 내 가장 빈도가 높은 키와 사용 횟수 (예: `java - xx회`)
2. **브라우저별 접속 통계**: Chrome, IE 등 브라우저별 접속 건수 및 백분율(%) 산출
3. **응답 성공/실패 횟수**: `200`(성공) 및 `404`(실패) 발생 건수 집계
4. **최다 요청 시간대**: 트래픽이 가장 집중된 시간대 파악 (예: `[10시]`)
5. **비정상 요청 분석**: `403`(권한 없음) 발생 건수 및 비율 산출
6. **특정 URL 에러 분석**: `books` 관련 요청 중 `500`(서버 에러) 발생 건수 및 비율 산출

### 3. 🔍 범위 지정 조회 기능 (7번)
* 콘솔 또는 `JOptionPane.showInputDialog`를 통해 특정 라인 범위(예: `1000~1500`)를 입력받아, 해당 구간 내 **최다 사용 키와 횟수**를 추출 및 출력합니다.

### 4. 🖥️ 메뉴 선택 및 출력 방식 (8번)
인증 완료 후 기능 선택 번호(`1` 또는 `2`)를 입력받아 분기 처리합니다.
* **메뉴 `1` (화면 출력)**: `JTextArea`와 `JOptionPane`을 활용하여 GUI 창에 1~7번 분석 결과 전체 출력
* **메뉴 `2` (파일 저장)**: 
  * `root` 계정 접근 시 `"문서를 생성할 수 있는 권한이 없음"` 경고 메시지 출력 후 중단
  * 일반 관리자 계정 시 `c:/dev/report` 폴더 생성 후 `report_타임스탬프.dat` (예: `report_1628605156919.dat`) 파일로 분석 결과 저장

## 📁 프로젝트 구조 (Architecture)
* **Login Module**: 사용자 계정 검증 및 권한 분기
* **View Module**: Swing 기반 대화상자 및 결과 텍스트 출력 컴포넌트 관리
* **Report Module**: 로그 파일 읽기, 데이터 파싱, 통계 연산 및 `.dat` 파일 출력 처리
